# Your Beacon Dental confirmation

Look for booking and rescheduling confirmations from `noreply@beacondental.test`.
They include your clinician and appointment date and time. Beacon does not include
patient contact details in confirmation messages.

This is a fictional demonstration: messages go to the local Mailpit inbox rather
than a real mail service. If a message is missing, check **My bookings** at
`/bookings` for the current appointment. For help, ask Bella Byrne at
`bella@beacondental.test`.

When the clinic has reminders switched on, you receive one reminder about 24 hours
before your appointment. It shows the date, UK time and clinician, with a link
to **My bookings** to reschedule or cancel after signing in. Cancelled bookings
get no reminder. If you move before the reminder is sent, it uses your new time
and clinician. A booking that has already had its reminder does not get another.

If reminders are switched off when yours is due, it is skipped. Switching them
on later does not send a reminder for the same booking time.
