# Your Beacon Dental confirmation

Look for booking and rescheduling confirmations from `noreply@beacondental.test`.
They include your clinician and appointment date and time. Beacon does not include
patient contact details in confirmation messages.

Booking and move confirmations also include `booking.ics`. Import this file into
Google, Outlook or Apple Calendar to see the clinic, your clinician, the time and
appointment length. UK clock changes are handled in the file. Your calendar shows
the time in its selected time zone, so choose UK time if you are travelling.

If you move an appointment, import the new file and check the new time. If your
calendar adds a duplicate, remove the old entry. Moving or cancelling does not
automatically update your calendar. Check **My bookings** for current details.

This is a fictional demonstration: messages go to the local Mailpit inbox rather
than a real mail service. If a message is missing, check **My bookings** at
`/bookings` for the current appointment. For help, ask Bella Byrne at
`bella@beacondental.test`.
