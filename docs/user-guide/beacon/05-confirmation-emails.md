# Your Beacon Dental confirmation

Look for booking and rescheduling confirmations from `noreply@beacondental.test`.
They include your clinician and appointment date and time. Beacon does not include
patient contact details in confirmation messages.

This is a fictional demonstration: messages go to the local Mailpit inbox rather
than a real mail service. If a message is missing, check **My bookings** at
`/bookings` for the current appointment. For help, ask Bella Byrne at
`bella@beacondental.test`.

Each booking and move confirmation includes an `appointment.ics` calendar file.
Open it in Google, Outlook or Apple Calendar to add your appointment. It includes
the clinic, clinician, UK time and full appointment length. You can also choose
**Add to calendar** after booking or moving, or beside a confirmed booking in
**My bookings**. Only you can download your own calendar file while signed in.

The file is a copy of the saved appointment, not a live calendar subscription.
If you move or cancel, update your calendar too. Download the latest file from
**My bookings** after a move. If a download or email fails, your booking stays saved.
