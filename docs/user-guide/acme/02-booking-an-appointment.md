# Booking a physiotherapy session

1. Sign in and choose **Book**.
2. Choose a **Physiotherapist** and **Date**, then select **Show times**.
3. Choose a free time. If there are no free times, use **Next day** or **Previous day**,
   or choose another date and select **Show times**.
4. Check the physiotherapist, date, time and length of your session. Select
   **Choose a different time** to return to the same day's times.
5. Select **Confirm booking**. You can leave the phone number blank.

Acme Physio sessions are **45 minutes**. You can book up to 220 days ahead.
All times are shown in the clinic's time zone. If someone books a time before
you confirm, choose another time. Your confirmed session appears in **My bookings**.
