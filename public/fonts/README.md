# Local typefaces

BookIt serves these WOFF2 files itself. No font service is contacted when a page loads.

- Fraunces: `@fontsource-variable/fraunces` 5.3.0, normal weight-axis Latin and Latin Extended subsets.
- Figtree: `@fontsource-variable/figtree` 5.3.0, normal weight-axis Latin and Latin Extended subsets.

Source archives: `https://registry.npmjs.org/@fontsource-variable/fraunces/-/fraunces-5.3.0.tgz` and
`https://registry.npmjs.org/@fontsource-variable/figtree/-/figtree-5.3.0.tgz`.
Both are licensed under the SIL Open Font Licence 1.1; the accompanying copyright and licence notices are kept
here. The font files are unmodified. The extended subsets support clinic and practitioner names with accents.
