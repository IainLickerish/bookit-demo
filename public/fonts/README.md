# Calendar screen fonts

Fraunces (500) and Figtree (400 and 500), with Latin and extended Latin
characters, are bundled as WOFF2 files. BookIt serves them locally and applies
them only while the calendar screen is open, following DS-3.

Source: `@fontsource/fraunces` and `@fontsource/figtree`, both version 5.3.0,
downloaded from the npm registry with their SHA-512 package integrity checked.
These are font assets, with no added runtime packages. Each font's SIL Open
Font Licence is included beside the files.
