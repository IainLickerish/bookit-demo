# BookIt fonts

Fraunces and Figtree are served locally as WOFF2 variable fonts, with Latin and
extended Latin subsets. Both are licensed under the SIL Open Font Licence 1.1.
The original licences are included alongside the fonts.

Unmodified files from Fontsource variable packages, version 5.3.0:

- https://www.npmjs.com/package/@fontsource-variable/fraunces/v/5.3.0
- https://www.npmjs.com/package/@fontsource-variable/figtree/v/5.3.0

These are bundled assets, not application dependencies. Pages make no requests
to Fontsource or Google Fonts.
