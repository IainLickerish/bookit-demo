# Clinic fonts

Figtree (400, 500 and 600) and Fraunces (500), normal Latin subsets, are served by
BookIt itself through Next.js local fonts. No visitor contacts a font provider.

The files come from `@fontsource/figtree` and `@fontsource/fraunces`, both version
5.3.0, published in the npm registry. Each font's SIL Open Font Licence is kept
beside it. These are static assets, with no added runtime package dependency.
